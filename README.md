# CI/CD Demo App

A simple Express API used to demonstrate a full CI/CD pipeline with Jenkins, SonarQube, Snyk, Docker, and Azure Container Registry.

## Local Development

\`\`\`
npm install
npm start
\`\`\`

## Run Tests

\`\`\`
npm test
\`\`\`

## Build Docker Image

\`\`\`
docker build -t cicd-demo-app .
\`\`\`
